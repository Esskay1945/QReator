# QReator
QReator - A lightweight, pure JavaScript QR code generator. Create scannable QR codes for URLs, emails, and WiFi networks instantly in your browser. No frameworks, no dependencies, just simple HTML/CSS/JS. 🔲✨



QReator 🔲
QReator is a lightweight, browser-based QR code generator that lets you create custom QR codes instantly without any backend or external dependencies (except the QR API).
✨ Features

URL QR Codes - Convert any web link into a scannable QR code
Email QR Codes - Generate codes that open email apps with pre-filled recipient, subject, and message
WiFi QR Codes - Create codes that automatically connect devices to WiFi networks

🚀 Quick Start

Download or clone the repository
Open index.html in any modern web browser
Select your QR code type
Enter the required information
Download your generated QR code

No installation, no dependencies, no configuration required!
💡 Use Cases

Share WiFi credentials with guests
Create promotional materials with website links
Generate contact QR codes for business cards
Quick email signature QR codes
Event marketing and ticketing

🛠️ Technology
Built with pure HTML, CSS, and JavaScript - no frameworks or build tools needed. Uses the QR Server API for QR code generation.
📱 Compatibility
Works on all modern browsers including Chrome, Firefox, Safari, and Edge. Fully responsive design works on desktop, tablet, and mobile devices.
